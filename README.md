## About

**SpotlightSAI** is an open-source, self-hosted platform for tracking and optimizing your **AI visibility**, also known as:

- Answer Engine Optimization (AEO)
- Generative Engine Optimization (GEO)
- LLM Optimization (LLMO)

It tracks how AI answer engines like ChatGPT, Claude, Perplexity, Gemini, Grok and Google AI Overviews mention, cite, and describe your brand — so you can benchmark competitors and grow your visibility in AI answers.

A free, auditable alternative to tools like Profound, Peec AI and Otterly. You run it on your own infrastructure, you own your data, and every metric can be traced back to code in this repository.

## Features

- **Visibility scoring** — for every tracked prompt, measure how often each engine mentions your brand, trended over time per prompt and per model.
- **Brand mention tracking** — answers are checked against your brand name, aliases, and domains, consistently across engines.
- **Citation analysis** — every cited URL stored with domain and position, categorized: your domains, competitors, social, Google properties, institutional sources.
- **Competitor benchmarking & share of voice** — leaderboard of competitor mention rates next to yours, over time.
- **Query fan-out analysis** — the web searches engines run while grounding answers: which rewrites they use, which ones your content wins or misses.
- **Prompt management** — onboarding wizard analyzes your website and suggests keywords, competitors, personas and prompts; add your own manually with tags.
- **Opportunities** — prioritized recommendations on what to create, pitch and seed to earn more AI citations.
- **Reports** — shareable visibility reports viewable by stakeholders without an account.
- **REST API** — manage brands, prompts, competitors; pull analytics snapshots programmatically.

## Quick Start

Requires Docker and an API key from a scraping provider (e.g. BrightData) plus one LLM key (OpenAI, Anthropic, Mistral or OpenRouter).

```bash
# Install the CLI
npm install -g @elmohq/cli

# Initialize configuration (interactive wizard)
elmo init

# Start the stack
elmo compose up -d
```

Once the services report healthy, open **http://localhost:1515** and create your account.

## How It Measures AI Visibility

The methodology is simple and fully inspectable in this repository:

1. **Prompts are defined per brand** — generated by the onboarding wizard from your website, or written by hand.
2. **A background worker runs each prompt on a schedule** against every configured engine. Scraping providers capture the real consumer surfaces (ChatGPT, Google AI Mode/Overviews, Gemini, Perplexity, Copilot); direct model APIs add coverage for Claude, Grok and others with web search enabled.
3. **Every answer is normalized and parsed** — answer text, cited URLs, query fan-out, model version. Text is scanned for brand names, aliases, domains, and competitors'.
4. **Everything is stored in PostgreSQL**, including raw engine output, so any metric can be re-derived and audited later. No black boxes.
5. **Metrics aggregate into trends** — visibility = share of runs mentioning your brand; share of voice compares you against competitors; citation counts roll up by URL, domain and category.

## Self-hosting & Architecture

| Option | What you get | Price |
|---|---|---|
| **Self-hosted** | Full platform via Docker Compose, unlimited prompts, all engines and providers | Free (MIT) |
| **White-label** | Custom branding, custom domain, SSO for agencies serving multiple clients | Custom |

A web app serves the dashboard and REST API, a worker schedules and executes prompt runs, PostgreSQL stores data and the job queue. See [CONTRIBUTING.md](CONTRIBUTING.md) for the monorepo layout and the developer guide.
